## 1. Aceptación de estos Términos

Al agregar Commie ("el Servicio") a un servidor de Discord, usar sus comandos, o iniciar sesión en su dashboard web complementario ("el Servicio Web"), aceptas quedar sujeto a estos Términos de Servicio. Si no estás de acuerdo, no uses el Servicio.

## 2. Descripción del Servicio

Commie es un bot de Discord que ofrece herramientas de moderación, tags personalizados, starboard, mensajes de bienvenida/despedida, autoroles, recordatorios, un sistema de tickets y un constructor de embeds. El Servicio Web es un complemento opcional y solo por invitación para configurar estas funciones desde un navegador en vez de comandos de Discord.

## 3. Contenido de Mensajes

Discord requiere que los bots soliciten un permiso privilegiado para recibir el contenido de texto de los mensajes. El Servicio usa esto únicamente para operar funciones específicas que requieren inherentemente leer el contenido de un mensaje para funcionar — por ejemplo, reproducir un mensaje en el starboard una vez que recibe suficientes reacciones, o incluir el texto de mensajes en la transcripción de cierre de un ticket de soporte.

No almacenamos contenido de mensajes más allá de lo que requiere el propio funcionamiento de cada función (por ejemplo, una entrada de starboard persiste mientras el mensaje destacado también lo haga; una transcripción de ticket persiste como parte del registro de ese ticket). Los desarrolladores del Servicio no leen el contenido de mensajes con ningún propósito fuera de operar estas funciones, y el contenido de mensajes nunca se vende, comparte con anunciantes, ni se usa para construir perfiles de usuario.

## 4. Cuenta de Discord y Autenticación (Servicio Web)

El Servicio Web se autentica exclusivamente mediante el flujo oficial OAuth2 de Discord. Nunca pedimos ni almacenamos tu contraseña de Discord. Iniciar sesión otorga al Servicio Web acceso de lectura a tu perfil de Discord y a la lista de servidores a los que perteneces, únicamente para determinar cuáles puedes administrar.

## 5. Acceso al Servicio Web

El acceso para configurar un servidor específico mediante el Servicio Web es solo por invitación, otorgado individualmente por el propietario/administrador del bot en ese servidor. Tener una cuenta de Discord o ser miembro de un servidor que use Commie no otorga por sí solo acceso al Servicio Web.

## 6. Uso Aceptable

Aceptas no usar el Servicio para:

- Violar los propios Términos de Servicio o las Normas de la Comunidad de Discord.
- Acosar, amenazar o abusar de otros usuarios mediante funciones como el sistema de tickets, embeds o recordatorios.
- Intentar obtener acceso no autorizado al Servicio Web, a la API subyacente, o a cualquier servidor o cuenta que no estés autorizado a administrar.
- Interferir con o interrumpir el funcionamiento del Servicio (incluyendo solicitudes automatizadas excesivas).

## 7. Responsabilidad del Propietario del Servidor y Usuarios

Los administradores del servidor son responsables de su configuración de funciones como embeds, mensajes de bienvenida, tags y tickets, incluyendo el contenido que decidan establecer y cómo se reenvía o muestra a los miembros de su servidor. El Servicio, su creador y su equipo de desarrollo no asumen responsabilidad alguna por el contenido que los administradores de servidor o usuarios configuren, almacenen, o hagan que el Servicio reenvíe, muestre o repita a través de cualquiera de sus funciones.

El Servicio se ofrece sobre una base de mejor esfuerzo, sin garantía de tiempo de actividad. Las funciones pueden cambiar, agregarse o eliminarse en cualquier momento, con o sin previo aviso.

Podemos suspender o revocar el acceso al Servicio Web, o remover el Servicio de un servidor, a nuestra discreción, incluyendo por violaciones a estos Términos.
