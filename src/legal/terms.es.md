## 1. Aceptación de estos Términos

Al acceder o usar el bot de Discord Commie ("Commie", "el Bot") o su dashboard web complementario ("el Dashboard", en conjunto "el Servicio"), aceptas quedar sujeto a estos Términos de Servicio. Si no estás de acuerdo, no uses el Servicio.

## 2. Descripción del Servicio

Commie es un bot de Discord que ofrece herramientas de moderación, tags personalizados, starboard, mensajes de bienvenida/despedida, autoroles, recordatorios, un sistema de tickets y un constructor de embeds, junto con un Dashboard web para configurar estas funciones por servidor de Discord ("guild").

## 3. Cuenta de Discord y Autenticación

El Dashboard se autentica exclusivamente mediante el flujo oficial OAuth2 de Discord. Nunca pedimos ni almacenamos tu contraseña de Discord. Iniciar sesión otorga al Dashboard acceso de lectura a tu perfil de Discord y a la lista de servidores a los que perteneces, únicamente para determinar cuáles puedes administrar.

## 4. Acceso al Dashboard

El acceso al Dashboard para configurar un servidor específico es solo por invitación, otorgado individualmente por el propietario/administrador del bot en ese servidor. Tener una cuenta de Discord o ser miembro de un servidor que use Commie no otorga por sí solo acceso al Dashboard.

## 5. Uso Aceptable

Aceptas no usar el Servicio para:

- Violar los propios Términos de Servicio o las Normas de la Comunidad de Discord.
- Acosar, amenazar o abusar de otros usuarios mediante funciones como el sistema de tickets, embeds o recordatorios.
- Intentar obtener acceso no autorizado al Dashboard, a la API subyacente, o a cualquier servidor o cuenta que no estés autorizado a administrar.
- Interferir con o interrumpir el funcionamiento del Servicio (incluyendo solicitudes automatizadas excesivas).

## 6. Responsabilidades del Propietario del Servidor

Si configuras Commie para un servidor de Discord, eres responsable de que tu uso de funciones como embeds, mensajes de bienvenida y tickets cumpla con la ley aplicable y las políticas de Discord, incluyendo respecto al contenido enviado a los miembros de tu servidor.

## 7. Disponibilidad

El Servicio se ofrece sobre una base de mejor esfuerzo, sin garantía de tiempo de actividad. Las funciones pueden cambiar, agregarse o eliminarse en cualquier momento, con o sin previo aviso.

## 8. Exención de Garantías

El Servicio se proporciona "tal cual" y "según disponibilidad", sin garantías de ningún tipo, expresas o implícitas, incluyendo pero no limitado a idoneidad para un propósito particular, no infracción, u operación ininterrumpida.

## 9. Limitación de Responsabilidad

En la máxima medida permitida por la ley aplicable, los operadores de Commie no serán responsables por daños indirectos, incidentales, especiales o consecuentes derivados de tu uso o incapacidad de usar el Servicio.

## 10. Terminación

Podemos suspender o revocar el acceso al Dashboard, o remover el Bot de un servidor, a nuestra discreción, incluyendo por violaciones a estos Términos.

## 11. Cambios a estos Términos

Podemos actualizar estos Términos periódicamente. La fecha de "Última actualización" en la parte superior de esta página refleja la revisión más reciente. El uso continuado del Servicio después de que los cambios entren en vigor constituye aceptación de los Términos revisados.
